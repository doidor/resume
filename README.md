## Resume
This is my public resume, focused on applied AI, developer platforms, and engineering leadership.

The editable source is [resume.json](resume.json); [resume.pdf](resume.pdf) is the matching export. Keep both files in sync when updating the resume.

Originally created with [Resumake](https://resumake.io/), using template 6. The hosted app has retired; its [original source and templates](https://github.com/saadq/resumake.io/tree/v2) remain available for local rendering.

The header summary is stored in `basics.summary` and appears below the contact details, before Skills. When rendering locally, customize template 6's `profileSection` to include the LaTeX-escaped summary as a left-aligned paragraph after the centered contact block; the upstream template omits this field by default.

Wrap work entries with four or fewer highlights in a full-width, left-aligned LaTeX `minipage` to keep their headings and bullets together.
